# Workshop handouts

Drop the handout files here using these exact names — the workshop pages
already link to them, and each link only appears once the file exists:

| Day    | HTML                    | PDF                    |
|--------|-------------------------|------------------------|
| Day 01 | `handouts/day-01.html`  | `handouts/day-01.pdf`  |
| Day 02 | `handouts/day-02.html`  | `handouts/day-02.pdf`  |
| Day 03 | `handouts/day-03.html`  | `handouts/day-03.pdf`  |

Until a file is added, its button is hidden and the page shows
"Handouts for this day are not published yet." Nothing 404s.
