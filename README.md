# ACM Programming Jam 2026

Official website for **ACM Programming Jam 2026 (JAM.26)**.

JAM.26 is an AI-assisted web engineering event designed to give students hands-on experience with the process of taking an idea from planning to production.

Participants prepare through a series of workshops before applying what they have learned during the Programming Jam competition.

## About JAM.26

The Programming Jam focuses on the modern web development workflow.

Participants learn how to:

- Plan application functionality and architecture
- Design user interfaces and experiences
- Build web applications with AI assistance
- Implement authentication and persistent data
- Debug and investigate technical problems
- Use version control
- Deploy applications to production
- Configure domains and DNS
- Evaluate performance, accessibility, and SEO
- Prepare websites for search engine discovery
- Adapt to changing requirements
- Present and explain their final solution

AI is intentionally part of the event.

Participants may use AI to generate part or all of their application. The emphasis is on using AI effectively while remaining responsible for testing, debugging, adapting, and delivering a working solution.

## Development Journey

The event follows a practical web engineering lifecycle:

PLAN → DESIGN → BUILD → CONNECT → DEBUG → DEPLOY → OPTIMIZE → PRESENT

The preparation workshops introduce this workflow.

Competition day challenges participants to apply it independently.
